ДОВОДКА ЭТОЙ ВЕРСИИ
Уточнён возврат фокуса после диалогов и закрытие поиска одним Escape. Общая пауза не отменяется кнопкой ядра; локальная пауза ядра сохраняется после переключения общих эффектов. Если в системе включено уменьшение движения, анимация остаётся выключенной.
По сохранённому отчёту предыдущего этапа в браузере были проверены основные сценарии команд, брифа, терминала, фильтров и пауз, а также ширины 320, 390 и 1440 px. Это результаты предыдущего этапа, не новый браузерный прогон.
При продолжении работы автономный HTML, dist и ZIP пересобраны. Локальные тесты прошли: уникальность 49 идентификаторов, якоря и связи HTML/JS, синтаксис JavaScript, встроенные стили/скрипт/иконка и соответствие всех 15 файлов ZIP текущим исходникам.
Ограничение проверки: новый прогон автономного HTML по локальному HTTP не начался — встроенный браузер отключён в настройках среды. Проверка открытия через file:// также не выполнена. Статические тесты не заменяют проверку отображения и взаимодействий в браузере; новых скриншотов нет. Для завершения этого этапа требуется доступный встроенный браузер.

НОВЫЕ ВОЗМОЖНОСТИ
Ctrl+K (на Mac Cmd+K) — поиск и быстрые команды. Стрелки выбирают, Enter выполняет, Escape закрывает.
Секция «Внутри системы» — локальный терминал. Начни с help; попробуй whoami, services, contact и secret. Стрелки — история, Tab — однозначное автодополнение.
Лайм / Хром / Янтарь — материалы 3D-ядра. Меняются кнопками на первом экране или командой theme chrome в терминале.
После прокрутки появляется нижняя панель. Кнопка «Эффекты» останавливает анимацию и движение карточек. Системное предпочтение уменьшенного движения учитывается.
В заявке — вопросы-подсказки по выбранному направлению, счётчик символов и экспорт текста в .txt. Подсказки вставляются только в пустую заявку.
Терминал — интерфейс сайта, не настоящая консоль компьютера. Произвольный код не выполняется. История хранится только в памяти текущей вкладки и исчезает после перезагрузки.

БЫСТРЫЙ ЗАПУСК
Открой roman-standalone.html двойным кликом. Это весь сайт в одном файле: стили, логика и графика внутри. Интернет требуется только для перехода в Telegram.

РЕДАКТИРОВАНИЕ
index.html — тексты, секции, ссылки и разметка.
styles.css — оформление и адаптивность.
app.js — фильтры, заявка, копирование, меню и WebGL-скульптура.
favicon.svg — иконка вкладки.
Промпт.txt — исходный дизайн-промпт.

ЛОКАЛЬНЫЙ СЕРВЕР
Нужен Node.js. Установка библиотек не требуется.
Команда: npm run dev
Адрес будет указан в терминале. По умолчанию используется порт 5173, доступ только с этого компьютера. Остановить сервер — Ctrl+C.

СБОРКА ПОСЛЕ ИЗМЕНЕНИЙ
npm run build
Обновляет автономный roman-standalone.html, каталог dist и архив roman-digital-site.zip. В ZIP включены актуальные исходники, автономный файл, dist, промпт, инструкция и тесты. Не редактируй автономный файл отдельно: изменения исходников применяются через сборку.

ПРОВЕРКА
npm test
Проверяет связи HTML/JS, идентификаторы, якоря, состав секций, синтаксис JavaScript и автономность сборки. Это статические проверки, они не заменяют проверку отображения в браузере.

ПУБЛИКАЦИЯ
На статический хостинг нужно загрузить содержимое dist, а не саму папку. Серверный код и база данных для сайта не нужны. В этой задаче сайт не публиковался в интернете и домен не подключался.

КАК РАБОТАЮТ ЗАЯВКИ
Кнопка карточки открывает бриф. Выбери направление, допиши задачу и скопируй текст. Отдельная кнопка открывает Telegram @no_i_lord. Отправку делает сам посетитель. Сайт не сохраняет заявки и не обрабатывает платежи.
